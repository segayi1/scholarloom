数据在本地，
插件只是窗口

服务只监听回环；插件不建第二份数据库。

DSH 面板文献工作台
→
本地服务127.0.0.1:8766
→
SQLite + PDFdata/
只监听 127.0.0.1；CSRF / Origin 检查；不新增远端请求。
  • 插件连不上时，浏览器里的本地版照常可用
  • 换端口只改 baseUrl，不用改代码或迁移数据
本地版server.py + web/端口、模型/Zotero、data/
插件版dsh-plugin/baseUrl、projectDir、autoStart
共同点同一份 data/插件不复制题录与 PDF

插件负责

  • 文献工作台面板与阅读状态
  • 四个工具、PDF 转发、健康检查
  • 服务没起时自动拉起

插件不负责

  • 不存题录、笔记或 PDF
  • 不接管模型密钥
  • 不修改 Zotero 库
为什么不让插件存数据？ 文献库要能长期备份、迁移、被别的工具读取；面板只是入口，不是仓库。

同一份 data/，两个入口。

三步，装进 DSH

本地服务先跑起来，再装插件。

Python 3.10+DSH desktop已有 data/ 或新库
01

启动本地版

python server.py --port 8766

浏览器打开 127.0.0.1:8766

02

安装插件

install.ps1 -Profile desktop

写入 scholarloom-workbench，配置 baseUrl

03

打开面板

DSH 左侧「文献工作台」

文库、原文、解读、问答同屏

验证面板能列出文库、打开 PDF，说明插件已接通。
先说清楚
  • 扫描版 / 纯图片 PDF 没有文本层，不能选字
  • 段落高亮是临时对照，不写回 PDF
  • 记忆页目前固定 project=default
github.com/segayi1/scholarloom docs/CONFIGURATION.md · dsh-plugin/config.example.yml
本地版和插件版可以同时用；换端口只改 baseUrl。
